# AI 根拠生成（Cloudflare Worker内）

## 目的
計算済みの指標・スコア内訳を、投資家向けの文章として要約する。価格予測は行わない。

## 実装
- ファイル: `worker/src/ai/rationale.ts`
- プロンプト: `worker/src/ai/prompts.ts`
- エンドポイント: OpenAI Responses API (`https://api.openai.com/v1/responses`)
- モデル: `gpt-4.1-mini`（必要に応じて変更可能）
- APIキー: `OPENAI_API_KEY`（未設定時はフォールバック文言を返す）
- 呼び出し抑制: クエリ `skip_ai=1` でAI生成をスキップ

### 出力フォーマット（厳守）
1. 結論（BUY/WATCH/PASS のどれかを明示）
2. 根拠（最大5点、番号付き、具体的な数値を含める）
3. 反証（買わない理由/注意点を2点）
4. 次のアクション（監視条件・損切り/利確の目安）
5. ディスクレーマ（投資判断は自己責任）

## エラーハンドリングと課金対策
- APIレスポンスが失敗した場合: レスポンスメッセージを evidence に入れつつフォールバック文言を返す
- クォータ不足時: フォールバック文言＋`/api/health`でキー有無を確認
- キャッシュ: `cache.ts`経由で同一ティッカーの結果をTTL付きキャッシュ
- コスト削減: 
  - UIで`skip_ai=1`を使った分析の先行確認
  - 同じティッカー連続リクエストはキャッシュで抑制
